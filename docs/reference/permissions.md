| Permission | Default | Description |
|---|---|---|
| `rexenvoys.use` | true | Help and list |
| `rexenvoys.start` | op | Start and stop an event |
| `rexenvoys.flare` | op | Give a flare |
| `rexenvoys.reload` | op | Reload the configuration |

Opening a crate does not check a permission. Anyone who can open a chest can take what is inside.
